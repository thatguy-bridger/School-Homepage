Class Schedule

A-Days

Enter dates in M.D.YYYY format, separated by commas (e.g., 8.18.2025, 8.20.2025).

B-Days

Enter dates in M.D.YYYY format, separated by commas (e.g., 8.19.2025, 8.21.2025).

No School Days

Holidays, breaks, teacher in-service days, etc. Same M.D.YYYY format as above. A date listed here overrides A/B Days -- no periods, no countdown, no calendar sync for that day. Nothing else gets shifted or rescheduled.

Period Times

Adjust the start and end times for each period. Use 24-hour format (e.g., 07:45 for 7:45 AM, 13:00 for 1:00 PM).

External Calendars

Read-only .ics feeds (sports schedules, school district calendars, etc.) shown alongside your notes. Fetched directly from the browser; if a feed blocks that, a public CORS-proxy is used as a fallback.

Google Calendar Sync

Publishes a live .ics feed via a secret GitHub Gist, which Google Calendar can subscribe to. The gist URL is unauthenticated once created — anyone with the link can read it, so keep it as private as the token below.
