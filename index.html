Class Schedule

A-Days

Enter dates in M.D.YYYY format, separated by commas (e.g., 8.18.2025, 8.20.2025).

B-Days

Enter dates in M.D.YYYY format, separated by commas (e.g., 8.19.2025, 8.21.2025).

No School Days

Holidays, breaks, teacher in-service days, etc. Same M.D.YYYY format as above. A date listed here overrides A/B Days -- no periods, no countdown, no calendar sync for that day. Nothing else gets shifted or rescheduled.

Period Times

Adjust the start and end times for each period. Use 24-hour format (e.g., 07:45 for 7:45 AM, 13:00 for 1:00 PM).

External Calendars

Read-only .ics feeds (sports schedules, school district calendars, etc.) shown alongside your notes. Fetched directly from the browser; if a feed blocks that, a public CORS-proxy is used as a fallback.

Google Calendar Sync

Publishes a live .ics feed via a secret GitHub Gist, which Google Calendar can subscribe to. The gist URL is unauthenticated once created — anyone with the link can read it, so keep it as private as the token below.

App Data Backup & Sync

Pushes everything this app stores -- classes, schedule dates, notes, reminders, calendar feeds, preferences -- into the same private gist as a second file, so you can pull it down on another device with just this same token. Manual, not live: whichever side you sync last wins, so push before you switch devices and restore right after.

Set as Site Defaults

Password-protected. Commits your current classes, schedule, theme, reminders, and calendar feeds straight to GitHub as the new defaults every fresh install of this app starts from. This edits the live source file directly and can't be undone from here.

Backup & Restore

Export everything in this app -- classes, schedule dates, notes, calendar feeds, and preferences -- as one file, and re-import it later on this or another device. The export includes your GitHub sync token if you've set one up, so keep the file as private as you would a password.

Portal Sync

For schools like Skyward with no API access: install the companion browser extension (in this app's portal-sync-extension folder), browse to your Skyward assignments page while logged in, then export the JSON from the extension's popup and import it here. Assignments with a date the app can understand are folded into Due Soon; the rest still show below so you can check them manually.

Simulate Date

Test the app as if it were a different date/time -- class schedules, countdowns, and "no school today" logic all use this instead of your real system clock while it's active. It keeps ticking forward in real time from whatever moment you pick, so clocks and countdowns still move. Nothing here is sent anywhere; it only affects this browser tab.
