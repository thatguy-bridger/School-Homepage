# 🎒 School Dashboard

A sleek, modern, single-page school dashboard built with **HTML, CSS, and vanilla JavaScript**. Designed to be a personal academic hub, it combines class management, scheduling, and a powerful calendar into a polished glassmorphism interface with zero backend required.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-active-success)
![Built With](https://img.shields.io/badge/Built%20With-Vanilla%20JS-yellow)

---

## ✨ Features

### 📚 Class Dashboard
- Create unlimited class categories
- Organize classes with drag-and-drop
- Assign custom colors to classes
- Add:
  - Class name
  - Teacher
  - Room
  - URL
  - Notes
- Duplicate or remove classes instantly
- One-click launch to class websites

---

### 📅 Calendar
- Month View
- Week View
- Agenda View
- Day View
- Automatic school schedule support
- Current class highlighting
- Live countdown to the next period
- Daily class previews
- Notes on calendar dates

---

### 🎨 Customization
- Light Mode
- Dark Mode
- System Theme
- Multiple accent color palettes
- Reduced Motion mode
- Beautiful glassmorphism UI
- Animated ambient background
- Cursor glow effects
- Smooth transitions throughout the application

---

### ⚙️ Scheduling
Configure:

- Bell schedule
- Period times
- A/B days
- Rotating schedules
- Class order

The dashboard automatically determines:

- Current period
- Next class
- Time remaining
- Today's schedule

---

### 📤 Import & Export

Export your data as:

- JSON backups
- ICS Calendar files

Import previous configurations at any time.

---

### 💾 Local Storage

Everything is stored locally inside your browser.

No account required.

No server required.

No data leaves your computer.

---

## 🖥️ Technologies Used

- HTML5

## 🚀 Getting Started

Simply clone the repository and open the HTML file.

```bash
git clone https://github.com/yourusername/school-dashboard.git
cd school-dashboard
```

Open:

```
index.html
```

That's it!

No installation required.

No build process.

No dependencies.
